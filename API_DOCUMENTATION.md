# MedGuard AI • REST API Documentation

MedGuard AI exposes a comprehensive RESTful API for electronic health record ingestion, optical character recognition (OCR), clinical rule evaluations, longitudinal biomarker analytics, and verifiable AI querying.

**Base URL:** `http://localhost:8000/api`  
**Interactive Swagger Docs:** `http://localhost:8000/docs`  
**ReDoc Reference:** `http://localhost:8000/redoc`

---

## 1. System Health

### `GET /health`
Returns the status of the FastAPI backend and database connectivity.

**Response:**
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "ai_provider": "gemini_mock_fallback",
  "database": "sqlite_connected"
}
```

## 2. Patient Management

### `GET /patients`
List all registered patient profiles.

**Response `200 OK`:**
```json
[
  {
    "id": "uuid-v4-string",
    "name": "Eleanor Vance",
    "date_of_birth": "1958-04-12",
    "gender": "Female",
    "reference_number": "MRN-10892",
    "known_allergies": "[\"Penicillin\", \"Amoxicillin\"]",
    "document_count": 3,
    "created_at": "2026-08-01T10:00:00Z"
  }
]
```

### `POST /patients`
Register a new patient.

**Request Body:**
```json
{
  "name": "Sarah Connor",
  "date_of_birth": "1985-05-12",
  "gender": "Female",
  "reference_number": "MRN-101",
  "allergies": ["Penicillin", "Sulfa drugs"]
}
```

### `GET /patients/{id}`
Retrieve a specific patient record by UUID.

### `PUT /patients/{id}`
Update patient details, date of birth, gender, MRN, and allergies list.

### `DELETE /patients/{id}`
Permanently delete a patient and cascade delete all associated documents, medications, alerts, and timeline events.

### `POST /patients/demo`
Seed or reset the synthetic clinical evaluation demo profile (`Eleanor Vance`) complete with:
- 3 Clinical Documents (Prescription, Discharge Summary, Chemistry Lab)
- Pre-configured drug-drug interaction (`Ciprofloxacin` + `Warfarin`)
- Duplicate therapy detection (`Metformin`)
- Allergy contraindication (`Amoxicillin` with Penicillin allergy)
- Longitudinal blood glucose and HbA1c lab trends

## 3. Documents & Ingestion

### `POST /patients/{patient_id}/documents`
Upload one or more medical documents (`multipart/form-data`).

**Supported formats:** `.pdf`, `.png`, `.jpg`, `.jpeg`, `.txt` (Max 20MB per file).

**Response `201 Created`:**
```json
{
  "message": "Uploaded 2 documents",
  "documents": [
    {
      "id": "doc-uuid-1",
      "original_name": "discharge_summary.pdf",
      "classification": "Discharge Summary",
      "processing_status": "pending",
      "size_bytes": 1048576,
      "created_at": "2026-08-05T06:00:00Z"
    }
  ]
}
```

### `GET /patients/{patient_id}/documents`
List all documents uploaded for a patient.

### `GET /documents/{id}/file`
Stream and download the raw binary file for preview or rendering in the browser.

### `POST /documents/{id}/process`
Trigger the multi-stage AI extraction and rule evaluation pipeline for a document:
1. Optical text OCR parsing (`PyMuPDF` / fallback)
2. Document classification
3. Entity extraction (Medications, Lab tests, Diagnoses, Dates)
4. Medical brand $\rightarrow$ Generic normalization
5. Clinical rule engine evaluation
6. Timeline reconstruction

### `DELETE /documents/{id}`
Delete a document and clean up associated extracted entities.

## 4. Clinical Cross-Checking & Analytics

### `GET /patients/{patient_id}/overview`
Get patient safety KPI summary:
- Total documents
- Total visits
- Current active medications count
- High-risk warnings count
- Abnormal lab results count
- Average AI confidence score

### `GET /patients/{patient_id}/alerts`
List all safety alerts generated by the clinical rule engine:
- Drug-drug interactions
- Duplicate therapy / same-class duplicates
- Allergy contraindications
- Dosage anomalies

**Sample Alert Item:**
```json
{
  "id": "alert-uuid",
  "patient_id": "patient-uuid",
  "title": "Severe Drug Interaction: Ciprofloxacin + Warfarin",
  "category": "Drug-Drug Interaction",
  "risk_level": "critical",
  "explanation": "Ciprofloxacin inhibits CYP1A2 and increases plasma concentrations of Warfarin, causing severe elevated bleeding risk and INR spikes.",
  "recommended_action": "Avoid co-administration or closely monitor INR levels daily. Consider alternative antibiotic.",
  "confidence": 0.96,
  "supporting_text": "Rx: Ciprofloxacin 500mg BID PO; Current Meds: Warfarin 5mg daily PO"
}
```

### `GET /patients/{patient_id}/timeline`
Retrieve the chronological patient trajectory sorted by date.

### `GET /patients/{patient_id}/medications`
Retrieve active and discontinued medications with generic mappings and dosages.

### `GET /patients/{patient_id}/lab-trends`
Retrieve longitudinal lab test results grouped by biomarker name with clinical normal ranges (`normal_range_min`, `normal_range_max`) and status (`normal`, `high`, `abnormal`).

## 5. Ask MedGuard AI (Conversational QA)

  "question": "Was a penicillin antibiotic prescribed despite the documented allergy?"
}

  "citations": [
    {
      "document_name": "emergency_visit_prescription.pdf",
      "document_id": "doc-uuid",
      "page": 1,
